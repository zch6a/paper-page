Abstract

This is a made-up paper, for the example page. We present Tiny Fields, a scene representation small enough to fit in a cache line and fast enough to render a new view in real time. A field of a few hundred α-blended points, fitted to a handful of input views, renders at 95% of real time on a laptop and matches larger methods on three benchmarks. Code and data are available.
