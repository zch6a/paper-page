# Polish log

### 2026-11-13 — development

**Why it exists**: the usual project page is a copied template repository filled in by hand (names, links, figures,
BibTeX), and the best-known template is no longer maintained. Everything a project page starts from is on arXiv.

**What it does**: `paper-page new <arXiv ID>` reads arXiv's API (title, authors, affiliations when present,
abstract, comment, categories, DOI) and the paper's source (figures and captions), and writes `page.json` (the page
as data, for the author to edit) and `index.html`; `render` makes the HTML again; `new --tex` works from a local TeX
project. The page has the `citation_*` tags Google Scholar reads, Open Graph tags (with `site_url`, the teaser in link
previews), a BibTeX block with a copy button, light and dark, and no outside resources. The design is its own.

**Tried on real papers** (pages kept in the scratchpad, never in the repository: the figures are the authors'):

- NeRF (2003.08934): venue "ECCV 2020 (oral)" and the project page found in the comment.
- DDPM (2006.11239): the code link found in the abstract; four figures with captions.
- Attention Is All You Need (1706.03762): the architecture figure as the teaser; three PDF figures listed.
- 3D Gaussian Splatting (2308.04079): the project page found.

What the real papers showed, fixed before the first commit:

1. **The teaser.** NeRF's and 3DGS's teasers are PDFs. The first version promoted the first raster figure to teaser,
   so the page led with a results table's neighbour. Now only the paper's first figure is the teaser; when it is a
   PDF, the page has none and the report says how to convert it (`pdftoppm`).
2. **Captions carried citation keys** ("from the Deep Blending dataset hedman2018deep"): `\cite`, `\ref`, `\label`
   and strike-out commands now go with their arguments; leftover commands (`\small`, `\centering`) are dropped,
   operators (`\log`, `\max`) kept as words.
3. **arXiv answered 429** after a few requests: the client now waits as told (Retry-After, up to a minute) or 10, 20,
   40 seconds, three times.

Found by the tests while writing them:

4. **A path-escape bug** in reading the source: `lstrip("./")` strips characters, so `../evil.tex` became
   `evil.tex` and was accepted. Rewritten (and the archive is never extracted anyway: only chosen images are
   written, under names the tool makes).
5. Spaces after TeX symbols were eaten (`\alpha \leq 0.5` → `α≤0.5`); a umlaut came out as a combining mark (NFC
   now); NeurIPS's `\And` between authors was not split; the venue pattern ignored case everywhere, so its "a name
   with capitals inside" rule did nothing (now only the words around it ignore case).

Also: files are written with LF on every system (the same page.json makes the same page), and a CI job renders the
made-up example and checks it is the committed one.

Tests: 28 (with doctests). ruff, mypy clean.

`pdftoppm` is installed, opt-in; more real papers, e.g. ones with affiliations in arXiv's metadata and ACM/CVPR

### 2026-11-13 — polishing round 1

**PDF figures are converted.** In this field the teaser is often a PDF (NeRF's and 3DGS's are), so the first version
left most pages without one. When poppler's `pdftoppm` is installed (MiKTeX includes it; poppler-utils on Linux),
PDF figures are converted: the first page, 1600 pixels wide, in a temporary folder removed afterwards, no shell, a
60-second limit. `--no-convert` turns it off; without pdftoppm the report says how to get it. The converter is
injected, so tests use a fake; a test runs the real pdftoppm on a PDF written by hand (skipped where it is not
installed; CI installs poppler on Linux so it runs there).

**Five real papers again** (NeRF, 3DGS, Latent Diffusion, Segment Anything, ViT; pages in the scratchpad only): all
five now have their real teaser (3 or 4 figures converted each). What they showed, fixed:

1. A photo-heavy figure became a large PNG (Segment Anything's teaser: 2.9 MB). A PNG over 600 KB is tried as JPEG
   (quality 85) and the smaller kept: 2.9 MB → 524 KB, 3DGS 967 KB → 182 KB; diagrams stay PNG.
2. Captions lost the papers' own macros ("masks generated by from" for `\model{}`): simple macros without arguments
   (`\newcommand`, `\providecommand`, `\def`) are expanded in captions, `\xspace` dropped.
3. A removed citation left a space before the comma ("best quality , while"): spaces before punctuation are dropped.
4. `--force` left the previous run's figures in the folder (`fig-1.jpg` beside the new `fig-1.png`): it now removes
   the `figures/fig-N.*` files paper-page names before writing; any other file there stays.
5. Links on unknown hosts were all called "Project page", even after "Code at": a link is now labelled by the words
   just before it within its own sentence ("our code is released at" → Code; "Project page with videos and code:" →
   Project page, which wins), else by its host. Checked on seven papers: the same labels as before where they were
   right; 3DGS first came out "Data" (the abstract's last word, "datasets.", was in the window), so the window stops at
   a sentence end and the abstract and comment are no longer joined.

Also: a line on stderr while the source downloads (it can take a while; `--figures 0` skips it); README (both),
SECURITY (running pdftoppm), CHANGELOG and the Skill describe the conversion; the README-options test now matches
hyphenated options.

**Five more real papers** (Instant NGP, DreamBooth, ControlNet, LoRA, DPO) and `--tex` on a real project layout
(ControlNet's source written out in the scratchpad):

1. ControlNet's teaser was its block diagram: CVPR/ICCV papers put the teaser in the title block as

2. DreamBooth listed "Project page" twice (the comment and the abstract each named one; the check compared against a
   list that never grew): one link of each kind, the comment's first.
3. `--tex` printed an empty "links:" line and found no links: the abstract's links are taken, "none" said otherwise.

`--tex` on ControlNet's layout: the authors from `Lvmin Zhang, Anyi Rao, and Maneesh Agrawala\\ Stanford`, the
abstract and the converted teaser, all right.

**First independent review** (13: 12 confirmed, 1 plausible, all fixed; tests in `tests/test_review_round1.py`).
The page's HTML held up (escaping, the accent color, links); the input side did not:

1. A gzip bomb inflated whole in memory (a 199 KB source took 437 MB): decompressed in one bounded step, refused past
   250 MB (the page is still made, without figures).
2. A corrupt archive crashed with a zlib traceback: it is no source now.
3. `--tex` followed symbolic links out of the project and published what they pointed to: links, and files reached
   through them, are skipped.
4. Two files that `\input` each other many times multiplied (k=6: 556 M characters, 56 s): each file once, within a
   size budget.
5. An unclosed `\begin{figure}` made the figure search quadratic (512 KB: 22 s): environments are paired in one pass.
6. A macro containing itself grew as k³ (600 bytes → 54 M characters): expansion stops when it runs away.
7. (plausible) A `--tex` file in a big folder read everything under it: 250 MB at most.
8. The venue was guessed for submissions, workshops and tracks ("NeurIPS 2023 submission" → NeurIPS 2023): not any
   more, as the README promised ("never guessed").
9. Letters were lost: `Mart\'{\i}nez`, `Bj\o rn`, `Stra\ss e`, `\AA`, `\LaTeX`, and URLs in abstracts were treated
   as TeX (`~ada/model_2` → ` ada/model₂`): special letters and logos handled, URLs left as they are.
10. Authors: LNCS's `\inst{1}` made every name be dropped; acmart's one `\author` per author kept only the first: both
    read now.
11. BibTeX escaped only & and %: `# _ $ ~ ^` too; "Ada Example Jr." gave the key `jr2024...` and `Jr., Ada Example`:
    suffixes are handled (`Example, Jr., Ada`).
12. A write that failed (a lone surrogate in page.json) emptied the old index.html: files are encoded first and
    replaced only when complete.
13. A figure path `figures/%2e%2e/%2e%2e/x.png` (a browser reads `..`) or with a tab hiding a scheme passed: refused.

Also from the review: `new` overwrote someone's own `figures/fig-1.png` when there was no page.json; it now refuses
without `--force`. The workflows were found sound.

### 2026-11-13 — polishing round 5

**Second independent review** (15: 14 confirmed, 1 plausible, all fixed; tests in `tests/test_review_round2.py`):

1. A failed source download (a 404 for the e-print link, the size cap, the network) stopped the whole command after the
   metadata had arrived, and no page was written: the figures are optional, so the page is made without them.
2. `\$10` lost its dollar sign, `\textasciitilde` became a space, `\{x, y\}` lost its braces: escaped characters are
   set aside before the steps that drop `$` and braces (and read `_` as a subscript), and restored at the end.
3. `Input\\Output` dropped "Output" (the second backslash was read as a command): line breaks are handled first.
4. A figure of subfigures took panel (a)'s caption: the figure's own caption (its last `\caption` outside subfigures)
   now. One image is still shown (the first panel), as the README now says.
5. When the first figure's image was missing from the source (`teaser.tif`, or `teaser.PNG` in capitals), a later
   figure became the teaser silently: the teaser is the paper's first figure, found or not, with a message; extensions
   match in any case.
6. Words before a link overrode an obvious host ("Code and data are available at github.com/..." → Data): GitHub,
   YouTube, Hugging Face datasets, Zenodo label themselves; the words label the rest.
7. `--tex` ignored the paper's macros in the title and abstract (`\ours: Fast Fields` → ": Fast Fields") and failed on
   ICML (`\icmltitle`, `\icmlauthor`): both handled.
8. A `\thanks` with nested braces leaked into the title ("Tiny FieldsFunded by X"): commands are dropped with their
   arguments, braces balanced (also in author blocks).
9. A `\captionof{figure}` with no image of its own (a TikZ teaser) took an earlier figure's image: only images after the
   last figure count.
10. The `\captionof` check was quadratic (8,000 of each: 3.5 s): a binary search over the figure spans.
11. `$90^\circ$` → "90^": degrees are °.
12. "the .ply format" lost the space before the dot: a space goes before a full stop only when the stop ends a word.
13. A too-large source printed two contradictory messages: one.
14. The hint for an EPS teaser suggested pdftoppm, which does not read EPS: it says so.
15. (plausible) Extensions were tried web images first, unlike pdfLaTeX (PDF first): when a figure is both `x.pdf` and
    a preview `x.png`, the PDF the paper prints is taken (converted), the PNG standing in when it cannot be.

Rechecked on four real papers: all teasers right; Segment Anything's is now its true Figure 1 (a panel caption had
picked another).

Tests: 80 (were 66). ruff, mypy clean.

### 2026-11-14 — v0.1.1

Putting every tool's skill into one marketplace (research-kit) and running `claude plugin validate` on each
showed this one's SKILL.md frontmatter did not parse: a plain YAML value with `: ` inside ("…: text size…")
starts a new key, so Claude Code loaded the skill with no description, and an agent would never pick it. The
description and compatibility values are quoted (a JSON string is a YAML double-quoted scalar); validation passes.
Released as 0.1.1 so that `v0`, which the marketplace installs from, carries the fix.
